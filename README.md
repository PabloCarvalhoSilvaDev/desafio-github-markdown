# Desafio de Github e Markdown

Desafio prático para colocar em prática conceitos de GitHub e Markdown.

## Repositório
- [x] Criar um repositório 
- [x] Adicionar um arquivo 'README.md'
- [x] Utilizar Github.dev para editar README.md
- [x] Repositorio deve ser público

## Colaboração
- [] Adicionar um colaborador ao repositório
- [] Realizar alterações, commits, pull requests e issues
